= Outils d'intégration ONTAP pour les datastores NFS dans les environnements VMware
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Découvrez les outils d'intégration ONTAP pour gérer, surveiller et protéger les banques de données NFS dans les environnements VMware, notamment ONTAP tools for VMware vSphere, le plug-in NFS VAAI et SnapCenter Plug-in for VMware vSphere.

NetApp fournit les outils suivants pour gérer et protéger les datastores NFS dans les environnements VMware :

* *link:https://docs.netapp.com/us-en/ontap-tools-vmware-vsphere-10/index.html["ONTAP tools for VMware vSphere"^]*: Intègre la gestion ONTAP dans le client vSphere pour le provisionnement, la surveillance et la gestion des banques de données NFS, et applique les paramètres d'hôte ESXi recommandés.
* *link:https://docs.netapp.com/us-en/nfs-plugin-vmware-vaai/index.html["Plug-in NetApp NFS pour VMware VAAI"^]*: Décharge les opérations de stockage telles que le clonage sur ONTAP, améliorant ainsi les performances et réduisant la charge sur les hôtes ESXi.
* *link:https://docs.netapp.com/us-en/ontap-tools-vmware-vsphere-10/protect/enable-storage-replication-adapter.html["Adaptateur de réplication de stockage (SRA)"^]*: S'intègre à VMware Live Site Recovery (anciennement VMware Site Recovery Manager) pour orchestrer la reprise après sinistre en utilisant la réplication ONTAP SnapMirror.
* *link:vmw-dr-gs.html["NetApp Disaster Recovery"]*: Orchestre la reprise après sinistre des machines virtuelles sur des datastores NFS depuis la NetApp Console.
* *link:https://docs.netapp.com/us-en/sc-plugin-vmware-vsphere/index.html["SnapCenter Plug-in for VMware vSphere"^]*: Fournit une sauvegarde et une restauration cohérentes en cas de panne et au niveau des VM pour les VM sur des datastores NFS.
* *link:https://docs.netapp.com/us-en/data-infrastructure-insights/index.html["Data Infrastructure Insights NetApp"^]*: Fournit une visibilité sur les performances et l'état de l'infrastructure de stockage ONTAP et VMware.


Ces outils rationalisent les opérations, améliorent les performances et assurent la protection des données pour les banques de données NFS dans les environnements VMware.
