= Flux de travail de déploiement pour la convergence des instances de serveur vCenter vers le domaine de gestion VCF avec des datastores VMFS
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Faites converger un cluster vSphere existant avec des datastores NetApp ONTAP VMFS vers un domaine de gestion VMware Cloud Foundation. Vous examinerez les exigences de configuration, déploierez les outils ONTAP et provisionnerez les datastores VMFS, puis utiliserez l’outil VCF Installer pour valider et utiliser vos composants existants, déployer les nouveaux composants requis et configurer la plateforme.

Ce flux de travail est également utilisé pour permettre l’utilisation de tout datastore VMFS pris en charge comme stockage principal pour le domaine de gestion VCF.

Pour un aperçu du processus de conversion, reportez-vous à la documentation VMware : https://techdocs.broadcom.com/us/en/vmware-cis/vcf/vcf-9-0-and-later/9-1/deployment/converging-your-existing-vsphere-infrastructure-to-a-vcf-or-vvf-platform-.html["Convergence de l'infrastructure virtuelle existante vers un VCF"].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Un"]link:vmw-vcf-mgmt-vmfs-requirements.html["Examiner les exigences de configuration"]
[role="quick-margin-para"]
Examinez les exigences clés pour la convergence des instances de serveur vCenter vers les domaines de gestion VCF à l'aide de banques de données VMFS.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Deux"]link:vmw-vcf-mgmt-vmfs-deploy.html["Déployez les ONTAP tools et provisionnez une banque de données VMFS prise en charge"]
[role="quick-margin-para"]
Déployez ONTAP tools for VMware vSphere et provisionnez un datastore VMFS pris en charge.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Trois"]link:vmw-vcf-mgmt-vmfs-converge.html["Converger le cluster vSphere vers le domaine de gestion VCF"]
[role="quick-margin-para"]
Utilisez l'outil d'installation VCF pour valider, réutiliser les composants existants et déployer de nouveaux composants qui constituent le domaine de gestion VCF.
