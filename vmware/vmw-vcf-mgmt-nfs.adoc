= Flux de travail de déploiement pour la convergence d'une instance de serveur vCenter vers un domaine de gestion VCF avec des banques de données NFS
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Faites converger un cluster vSphere existant avec des datastores NetApp ONTAP NFS vers un domaine de gestion VMware Cloud Foundation. Vous examinerez les exigences de configuration, déploierez les outils ONTAP et provisionnerez les datastores NFS, puis utiliserez l'outil VCF Installer pour valider et utiliser vos composants existants, déployer les nouveaux composants requis et configurer la plateforme.

Ce flux de travail est également applicable si les banques de données ONTAP NFS 4.1 doivent être utilisées comme stockage principal pour le domaine de gestion VCF.

Pour une vue d'ensemble du processus de convergence, reportez-vous à la documentation VMware : https://techdocs.broadcom.com/us/en/vmware-cis/vcf/vcf-9-0-and-later/9-1/deployment/converging-your-existing-vsphere-infrastructure-to-a-vcf-or-vvf-platform-.html["Convergence de l'infrastructure virtuelle existante vers un VCF"].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Un"]link:vmw-vcf-mgmt-nfs-requirements.html["Examiner les exigences de configuration"]
[role="quick-margin-para"]
Examinez les exigences clés pour la convergence des instances de serveur vCenter vers le domaine de gestion VCF à l'aide de banques de données NFS.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Deux"]link:vmw-vcf-mgmt-nfs-deploy.html["Déployer les outils ONTAP et provisionner une banque de données NFS"]
[role="quick-margin-para"]
Déployez les ONTAP tools for VMware vSphere et provisionnez une banque de données NFS.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Trois"]link:vmw-vcf-mgmt-nfs-converge.html["Converger le cluster vSphere vers le domaine de gestion VCF"]
[role="quick-margin-para"]
Utilisez l'outil d'installation VCF pour valider, réutiliser les composants existants et déployer de nouveaux composants qui constituent le domaine de gestion VCF.
