Passez en revue les exigences d’ajout de banques de données iSCSI en tant que stockage supplémentaire à un domaine de gestion VMware Cloud Foundation (VCF).



[[infrastructure-requirements]]
== Exigences en matière d'infrastructure

Assurez-vous que les composants et configurations suivants sont en place.

* Un système de stockage ONTAP AFF ou ASA avec des ports de données physiques sur des commutateurs Ethernet dédiés au trafic de stockage.
* Le déploiement du domaine de gestion VCF est terminé et le vSphere web client est accessible.




[[recommended-iscsi-network-design]]
== Conception de réseau iSCSI recommandée

Vous devez configurer des conceptions de réseau entièrement redondantes pour iSCSI.  Le diagramme suivant montre un exemple de configuration redondante, offrant une tolérance aux pannes pour les systèmes de stockage, les commutateurs, les adaptateurs réseau et les systèmes hôtes. Consultez NetApplink:https://docs.netapp.com/us-en/ontap/san-config/index.html["Référence de configuration SAN"] pour plus d'informations.

image:vmware-vcf-asa-074.png["Conception de réseau iSCSI"]{nbsp}

Pour la gestion des chemins multiples et le basculement sur plusieurs chemins, créez au minimum deux LIF par nœud de stockage sur des réseaux Ethernet distincts pour toutes les SVM en configuration iSCSI. Avec ONTAP 9.19.1 et versions ultérieures, vous pouvez activer l'option de multipathing actif-actif symétrique sur les SVM sur AFF. Dans ASA, le multipathing actif-actif symétrique est activé par défaut.


TIP: Lorsque plusieurs adaptateurs VMkernel sont configurés sur le même réseau IP, il est recommandé d'utiliser la liaison de port iSCSI logicielle sur les hôtes ESXi afin d'assurer l'équilibrage de charge entre les adaptateurs. Consultez l'article de la base de connaissances link:https://knowledge.broadcom.com/external/article?legacyId=2038869["Considérations relatives à l'utilisation de la liaison de port iSCSI logicielle dans vSphere"^].
